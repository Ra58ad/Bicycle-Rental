# Bicycle Rental System

A basic system for handling the common operations in a bicycle rental store.

## Description

This project is part of an internship task that's based on refactoring an earlier university team project in order to:

* Learn basic system architecture
* System design principles like YAGNI, DRY, etc
* Modern Java programming with concepts like lambda programming and tools like Maven
* System design patterns that significantly expand university-level OOP programming, with patterns like Singletons, Builders, etc
* Testing with tools like JUnit
